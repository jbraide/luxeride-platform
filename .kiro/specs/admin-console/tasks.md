this spec depends on, not new work; each carries the file that proves it. Everything else is

> **Two different ladders.** The `_(P0)_` / `_(P1)_` / `_(P2)_` tags are the urgency definitions from
> `_CONTEXT.md` §12: P0 blocks going live or blocks paid traffic this week; P1 is required in the

> sibling spec it is written as `_(P1 — after commerce-backend)_`.

> is blocked on `commerce-backend` delivering Postgres. This is deliberate and it is Requirement 11:

> artefact a single-operator console must never produce (`fitment-engine` Requirement 12).
